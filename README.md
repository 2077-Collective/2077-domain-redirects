# 2077 domain redirects

This project owns only the legacy public-domain redirects:

- `2077.xyz` and `www.2077.xyz` redirect to `https://research.2077.xyz`.
- `etherpedia.2077.xyz` preserves the requested path while redirecting to
  `https://etherpedia.2077collective.xyz`.

The Research and Collective applications are deployed from separate repositories
and Vercel projects.
